# Original CartoDEM workflow

These are the original scraping, contour, COG, naming and packaging scripts
from before the EGM2008 workflow. `steps.sh` records the GDAL/rio-rgbify commands
and their zoom-dependent quantization.

The current pipeline is documented in [../egm2008/README.md](../egm2008/README.md).
Superseded EGM2008 experiments remain available in Git history.
